# VibeCode Bitrix Showcase

Статическая витрина (каталог кейсов) проектов, которые сообщество создало на платформе **Битрикс24 VibeCode**: дашборды, калькуляторы, ИИ-ассистенты, транскрибация, чат-боты и DevTools-инструменты.

Сайт показывает 63 кейса, сгруппированных по 10 категориям. Оформление светлое, рассчитано на чтение. Каждый кейс раскрывается как аккордеон с описанием решения, ключевыми возможностями, техническими тегами и метаданными. Слева есть навигация по категориям и живой поиск.

Это одна HTML-страница без сборки и без зависимостей: никаких `npm install` и build-шагов не нужно.

## Структура страницы

- **Боковое меню (`#sidebar`).** Логотип, поиск по названию и автору, ссылки на категории с бейджами-счётчиками, кнопки «Раскрыть все» / «Свернуть все», счётчик кейсов.
- **Hero-блок.** Заголовок и кнопка «Официальный сайт VibeCode».
- **Категории (`section.category-section`).** Каждая имеет `id`, который совпадает с якорем в меню:
  - `#analytics` — Сводная аналитика и BI-дашборды (11 кейсов);
  - `#calculators` — Расчётные калькуляторы и бизнес-логика (5);
  - `#ai-voice` — ИИ-ассистенты, голос и транскрибация (8);
  - `#bots` — Чат-боты и автоматизация (10);
  - `#devtools` — DevTools, SDK и MCP-интеграции (7);
  - `#crm-internal` — CRM и внутренние процессы (8);
  - `#client-services` — Клиентские сервисы и сайты (4);
  - `#docs-accounting` — Документы и бухгалтерия (3);
  - `#integrations-access` — Интеграции и доступ (4);
  - `#ai-infra` — ИИ-инфраструктура и собственные модели (3).
- **Карточка кейса (`.accordion-item`).** Заголовок с автором, а в теле — описание, список возможностей или цитата из чата, теги технологий и блок `meta-box` с размещением, сроком создания и т. п.

## Поведение (`app.js`)

- **Мобильное меню.** Кнопка «Меню» переключает класс `mobile-open` у сайдбара. На ширине до 1024 px меню закрывается после клика по ссылке.
- **Аккордеоны.** Клик по заголовку переключает класс `active`. Несколько карточек можно раскрыть одновременно.
- **Раскрыть / свернуть всё.** Добавляет или убирает `active` у всех карточек.
- **Поиск.** Фильтрует карточки по текстовому содержимому (название, автор, описание). Если запрос длиннее одного символа, найденные карточки раскрываются. Пустые категории скрываются, а счётчик «Кейсов» в сайдбаре показывает число совпадений.
- **Клавиатура.** `/` ставит фокус в поиск, `Esc` очищает поиск или закрывает мобильное меню. Заголовки кейсов — кнопки внутри `h3`, `Enter` и `Space` раскрывают карточку.
- **Подсветка навигации.** При прокрутке класс `active` получает ссылка на текущую категорию.

## Запуск

Откройте `index.html` в браузере. Для локального просмотра через HTTP-сервер:

```bash
python3 serve.py
```

Скрипт `serve.py` отдаёт файлы с отключённым кэшем: обычной перезагрузки страницы достаточно, чтобы увидеть изменения. Порт по умолчанию 8000, можно указать другой: `python3 serve.py 8080`.

После этого страница доступна на `http://localhost:8000`.

Шрифт Inter Variable лежит в `assets/fonts/`, интернет для вида не нужен.

Пересобрать токены после изменения дизайн-системы:

```bash
node /Users/asmadey/.claude/skills/popizdim-design/tools/build-tokens.mjs --out design
```

Футер указывает на возможный деплой на GitHub Pages или Vercel. Конфигурации деплоя в репозитории нет, достаточно раздать статические файлы из корня.

## Про `about.md`

Это текст статьи, а не документация к коду сайта. В нём описано приложение «Паспорт клиента»: TypeScript-сервер с маршрутами `http.ts`, сбором данных через Batch API в `passport.ts`, клиентом VibeCode API в `vibe.ts` и регистрацией placements `LEFT_MENU` и `CRM_COMPANY_DETAIL_TAB`. Исходников этого приложения в репозитории нет: файлы `src/…` из статьи здесь отсутствуют.

## Известные неточности

- Число кейсов в hero-блоке, счётчик в боковом меню и счётчики категорий заданы вручную в HTML и не вычисляются из разметки. При добавлении кейса обновите все четыре места.
- В `app.js` есть неиспользуемая переменная `isActive` в обработчике аккордеона.
- В `about.md` остались артефакты копирования (фрагменты «Объяснить с», пустые ссылки `[]()`).
